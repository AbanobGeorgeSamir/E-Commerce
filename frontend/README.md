# Frontend

React/Vite storefront for Luxe Store.

Use `frontend/.env.example` to create the required local `.env` file, then run:

```powershell
npm ci
npm run dev
```

Before deployment, run `npm run lint` and `npm run build`. The app is deployed from this directory as the frontend Vercel project; full setup instructions are in the repository [README](../README.md).
